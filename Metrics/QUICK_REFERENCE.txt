KEY INSIGHTS
─────────────────────────────────────────────────────────────────────────────────

✅ STRENGTHS
  1. Complete Heart Block nearly perfectly classified (93.64% F1)
  2. Very high ROC-AUC (90.16%) - excellent discrimination
  3. Production-ready hybrid architecture
  4. Interpretable attention mechanisms for explainability

⚠️  CHALLENGES
  1. Normal class severely underdetected (17.25% recall)
     → Model too conservative in Normal predictions
  2. RBBB poorest performance (46.63% F1)
     → Frequently confused with AV Block and other classes
  3. Normal class high precision but low recall
     → Precision: 91.12% | Recall: 17.25%

🚀 PHASE 2 RECOMMENDATIONS

  2. Address class imbalance with SMOTE/weighted sampling

  4. Contrastive learning for Normal class discrimination
  5. Clinical validation with real patient data

METRICS DEFINITIONS
─────────────────────────────────────────────────────────────────────────────────
Accuracy:        (TP + TN) / (TP + TN + FP + FN)
Precision:       TP / (TP + FP) - "When we predict positive, how often correct?"
Recall:          TP / (TP + FN) - "Of actual positives, how many do we catch?"
F1-Score:        2 × (Precision × Recall) / (Precision + Recall)
ROC-AUC:         Area under ROC curve (0 to 1, higher is better)

Macro Average:   Simple average across all classes (equal weight)
Weighted Avg:    Average weighted by class support (accounts for imbalance)
